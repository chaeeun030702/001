function kbText(dom) {

}

function parseDataUrl(s) {
  var m = /^data:(image\/(?:jpeg|png|webp|gif));base64,([A-Za-z0-9+/=]+)$/.exec(String(s || ''));
  if (!m) return null;
  return { mime: m[1], b64: m[2] };
}

function apiHeaders(key) {
  var h = { 'content-type': 'application/json', 'x-api-key': key, 'anthropic-version': '2023-06-01' };
  if (WORKSPACE) h['anthropic-workspace-id'] = WORKSPACE;
  return h;
}

function clamp(v, lo, hi) { v = Number(v); return isFinite(v) ? Math.min(hi, Math.max(lo, v)) : (lo + hi) / 2; }

function extractJson(text) {
  var t = String(text || '').trim();
  t = t.replace(/^```(?:json)?\s*/i, '').replace(/\s*```$/, '');
  var a = t.indexOf('{'), b = t.lastIndexOf('}');
  if (a < 0 || b < 0) throw new Error('no_json');
  return JSON.parse(t.slice(a, b + 1));
}

# e-safety — 전기설비부문 다국어 위험성평가표·사전작업허가서 자동 웹생성 플랫폼

**https://e-safety.vercel.app**

충북대학교 안전공학과 이채은 · 지에스건설 이명진
「Database 기반 생성형 AI 활용 전기설비부문 다국어 위험성평가표, 사전작업허가서 자동 웹생성 연구」 9·10단계 산출물

## 동작

1. **사진 업로드** → 생성형 AI(Claude 비전)가 사진을 보고 지식베이스 19종 가운데 실제로 확인되는
   위험 표지를 **위치·근거·확신도**와 함께 고른다(`/api/read`).
2. 좌측 **체크리스트**에서 표지를 더하거나 빼면(보정 조건 4종 포함) 세 문서가 즉시 다시 작성된다.
3. 우측에 **① 현장사진 기반 위험 판독 → ② 위험성평가표(3×3) → ③ 사전작업허가서**가 A4 지면으로
   생성되고, 모든 한글 항목 아래에 선택한 언어(영어·중국어·베트남어·우즈베키스탄어)가 병기된다.

AI 판독을 쓸 수 없으면(키 미설정·오류) 파일명·현장 정보 **키워드 판독**으로 자동 대체되고,
**직접 선택** 모드에서는 체크리스트만으로 작성할 수 있다.

## 구성

`/api/read`는 Vercel 프로젝트 환경 변수가 있어야 동작한다.

| 변수 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic API 키 (Settings → Environment Variables 에서 직접 입력) |
| `ANTHROPIC_WORKSPACE_ID` | 워크스페이스에 묶이지 않은 키(`sk-ant-usr-…`)를 쓸 때 필수 — Console 워크스페이스 ID |
| `ANTHROPIC_MODEL` | (선택) 기본값 `claude-sonnet-5-5` |

`GET /api/read` 로 상태를 확인할 수 있다 — `{"ok":true,"key":true,...}` 이면 키가 잡힌 것이다.
`GET /api/read?test=1` 은 서버 키로 짧은 요청을 실제로 보내 결과(`test.status`, 오류 메시지)를 보여준다. `commit` 은 배포된 커밋이다.
사진은 브라우저에서 최대 1,600 px로 줄여 전송되며 서버에 저장되지 않는다.
