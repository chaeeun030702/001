README.md

차분하고 신뢰감 있는 **라이트 우선 엔터프라이즈 UI**. 설명은 문단보다 **표·차트·다이어그램·Stat 타일**로 한다. 대시보드, 보고서, 분석 문서, 관리자 화면, 가이드 사이트에 쓴다.

## 한눈에

| 축 | 규칙 | 토큰 |
| --- | --- | --- |
| 톤 | 차분·신뢰·운영 지향. 그라디언트·블롭·장식 일러스트 금지 | — |
| 주 색 | Blue 하나만 인터랙션 색 | `primary` |
| 표면 | 흰색 + 쿨 뉴트럴, 셸과 캔버스 분리 | `bg-default` / `bg-canvas` |
| 글꼴 | Pretendard, 굵기 400·600·700만 | `font-sans`, `font-mono` |
| 숫자 | 표·지표는 tabular numerals | `eu-num` |
| 깊이 | 보더·여백 먼저, 그림자는 최소 | `border-default`, `shadow-0`~`4` |
| 모서리 | 8–16px, pill은 칩·토글만 | `radius-sm`/`md`/`lg`/`pill` |
| 설명 방식 | 3줄 넘는 산문 → 표·차트·다이어그램 | 아래 콘텐츠 원칙 |

## 콘텐츠 원칙

| 내용 유형 | 이렇게 표현 | 컴포넌트 |
| --- | --- | --- |
| 핵심 지표 | 큰 숫자 + 라벨 + ▲▼ 변화량 | `StatTile` |
| 2개 이상 항목 비교, 반복 속성 | 표 | `Table` |
| 시간 추세 | line | `Chart` |
| 구성·순위 | 정렬된 bar / stacked | `Chart` |
| 부분-전체(범주 ≤5) | donut | `Chart` |
| 순서·흐름 | 단계 다이어그램 | `FlowDiagram` |
| 상태 | 점 + 문구 배지 | `Badge` |
| 표·차트가 못 담는 맥락 | 짧은 문장 1–2개 | body1 |

- 문장은 자연스럽게 쓰되 **문단 개수와 길이**를 줄인다. 목표: 산문 1/2~1/3, 시각 요소 2배 이상.
- 차트 내용을 문단으로 반복하지 않는다.
- 사용자 쪽 언어로 쓴다. 버튼은 동사로 시작("공고 등록"), 결과는 과거형("저장했습니다"), 오류는 고치는 방법을 말한다.
- 존댓말(합니다체). 이모지 금지.

## 색

**Blue(`primary`)만 주 액션.** orange·pink를 주 액션에 쓰지 않는다. `accent-*`는 차트와 강조에만. `success`/`warning`/`error`는 상태 의미로만 쓰고 항상 텍스트를 함께 둔다.

| 역할 | 토큰 | 어디에 |
| --- | --- | --- |
| 셸 | `bg-default` | 헤더, 사이드내비 |
| 콘텐츠 캔버스 | `bg-canvas` | 셸 안쪽 스크롤 영역 |
| 카드·다이얼로그 | `surface-default` + `border-default` | 모든 카드 |
| 보조 면 | `bg-alt`, `surface-alt-1`/`2` | 표 헤더, hover, 스켈레톤 |
| 본문 / 보조 / 캡션 | `text-default` / `text-sub` / `text-caption` | 위계는 색보다 크기·굵기로 |
| 조용한 강조 | `primary-subtle` | 선택 행, 현재 메뉴, 정보 Alert |
| 상태 배경 | `success-subtle` 등 | Badge, Alert |
| 딤 | `overlay-scrim` | Dialog, Bottom sheet |

**다크 테마**는 자동 반전이 아니라 전용 다크 값을 쓴다(셸 `#1D1F24`, 캔버스 `#15171C`). page·card·input·table·dialog의 대비를 확인한 뒤 확정한다 `[Check]`.

## 타이포그래피

`font-sans`(Pretendard) 하나로 모든 텍스트를 쓴다. 데이터·코드·ID만 `font-mono`. 굵기는 400(본문)·600(라벨·강조)·700(제목·지표)만.

| 그룹 | 스타일 | 크기 / 굵기 | 용도 |
| --- | --- | --- | --- |
| Display | `display1`–`4` | 64·56·44·36 / 700 | 히어로 지표 |
| Title | `title1`–`3` | 32·28·24 / 700 | 페이지·섹션 제목 |
| Heading | `heading1`–`3` | 22·20·18 / 700 | 카드·블록 제목 |
| Body | `body1`–`3` | 16·15·14 / 400 | 본문·표 |
| Label | `label1`–`2` | 13·12 / 600 | 라벨·배지·표 헤더 |
| Caption | `caption1`–`3` | 11·10·9 / 400 | 축·메타·각주 |

척도 밖의 크기·굵기를 만들지 않는다. 한 데이터 맥락에서 tabular/proportional 숫자를 섞지 않는다.

## 아이콘

- **Icons** 그룹의 선형 아이콘만 쓴다: 24px 캔버스, stroke 1.5, round cap. compact 20·16px.
- UI에서는 `EUI.icon('bell')` 또는 `<span data-eu-icon="bell">`로 인라인 SVG를 넣는다(`currentColor` 상속).
- 상태 변화는 색·투명도로 표현하고 모양을 다시 그리지 않는다. 이모지·3D·마스코트·채움 아이콘 금지.
- 아이콘만 있는 버튼엔 `aria-label`, 필요하면 `Tooltip`.

## 브랜드 표기

로고·브랜드 락업·파비콘 규칙은 적용하지 않는다. 헤더에는 **서비스명 텍스트**만 `heading3`로 한 줄에 둔다.

## 접근성

| 항목 | 규칙 |
| --- | --- |
| 키보드 | 모든 컨트롤 Tab·Enter·Space로 작동 |
| focus | 2px `primary` 실선 링, offset 2px(`:focus-visible`) |
| 색 의존 | 상태는 색 + 텍스트/기호(▲▼, 점+문구) |
| 모달 | 포커스 트랩, Esc 닫기, 닫으면 포커스 복귀(`EUI.openDialog`) |
| 폼 | 라벨 `for`/`id`, 오류는 `aria-invalid` + `aria-describedby` 문구 |
| 비활성 | 조작 불가 + `bg-disabled`/`text-disabled`로 구분 |
| 모션 | `prefers-reduced-motion`이면 스켈레톤·스피너 정지 |

## 사용법

1. `tokens.css`와 `components/bundle.css`를 불러오고, 루트에 `data-theme="light"` 또는 `"dark"`를 둔다.
2. `components/bundle.js`를 넣으면 `window.EUI`(`icon`, `hydrate`, `openDialog`, `toast`)가 생긴다. 프레임워크 없이 동작한다.
3. 컴포넌트는 `eu-` 클래스로 조립한다. 각 컴포넌트 README의 표가 클래스·토큰·상태를 정의한다.
4. hex·px를 하드코딩하지 말고 토큰 변수(`var(--primary)`, `var(--space-4)`)만 쓴다.

# Chart

추세·구성·분포는 문단 대신 차트. 인라인 SVG + `eu-chart` 클래스, 색은 전부 토큰.

| 질문 | 차트 | 비고 |
| --- | --- | --- |
| 시간에 따라 어떻게? | line (+ 옅은 area) | 끝점 강조 + 값 라벨 |
| 무엇이 큰가? | bar (정렬) | 막대 위 값 라벨, 축 최소화 |
| 부분-전체 | stacked bar / donut | donut은 범주 ≤5 |
| 관계 | scatter | |
| 파이 | 지양 | |

**계열 색 순서**: `s1` `primary` → `s2` `accent-skyblue` → `s3` `accent-purple` → `s4` `accent-orange` → `s5` `accent-pink`. 단일 계열이면 `primary`만.

- 격자 `divider-default`, 축 라벨 `text-caption` 11px tabular, 값 라벨 `text-strong` 12/600.
- 모든 SVG에 `role="img"` + `aria-label`. 범례는 `eu-legend`.
- `success`/`error`는 상태 의미일 때만 계열 색으로 쓴다.
- [Check] s3(purple)–s5(pink)는 색각 이상에서 가깝다: 5계열이면 직접 라벨 병기.

# Input

라벨은 항상 보이고 `for`/`id`로 연결. placeholder는 예시일 뿐 라벨이 아니다.

| 상태 | 표현 |

| 오류 | `aria-invalid="true"` → `error` 보더 + 아이콘 + 문구(`aria-describedby`) |
| 비활성 | `bg-disabled` · `text-disabled` |

- 긴 선택지는 `select.eu-input.eu-select`.
- [Check] `border-strong`은 흰 배경 대비 1.55:1 — 원문 값 유지, 라벨·focus 링으로 보완.

# Toast

저장·삭제·재시도 결과 같은 일시 피드백. 4초 후 자동 소멸.

| 항목 | 값 |

| 아이콘 | tone별 `success`/`warning`/`error` 색, 기본 `info` |
| 위치 | 우하단, `space-5` 여백 |
