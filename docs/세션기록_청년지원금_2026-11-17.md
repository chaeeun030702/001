### 요청 2 — "perplexity에 대해서 설명해줘"

**답변 (원문)**

Perplexity라는 이름은 두 가지를 가리킵니다. 보통은 AI 검색 서비스를 말하지만, AI 분야에서는 언어모델을 평가하는 지표 이름이기도 합니다.

**1. Perplexity AI (검색 서비스)** — 질문하면 웹을 찾아보고, 출처를 붙인 답을 써 주는 AI 검색 엔진. 2022년 미국 스타트업 Perplexity AI가 만듦.

- 동작: ① 실시간 웹 검색 → ② 찾은 문서를 AI 모델(GPT, Claude, 자체 Sonar 등)이 읽고 요약 → ③ 문장마다 [1] [2] 출처 번호 표시

| 기능 | 설명 |
|---|---|
| 기본 검색 | 빠르게 출처가 붙은 답을 줌 |
| Pro Search / Deep Research | 여러 번 검색해 긴 조사 보고서를 만듦 |
| 후속 질문 | 대화하듯 이어서 물어볼 수 있음 |
| Spaces | 주제별로 자료와 검색을 모아 둠 |
| Comet 브라우저 | AI가 내장된 자체 웹 브라우저 |
| API (Sonar) | 개발자가 검색 기능을 프로그램에 붙일 수 있음 |

| | Perplexity | ChatGPT / Claude |
|---|---|---|
| 강점 | 최신 정보, 출처 표시 | 글쓰기, 분석, 코딩, 긴 대화 |
| 성격 | "답을 주는 검색 엔진" | "대화형 AI 비서" |
| 출처 | 기본으로 붙음 | 검색 기능을 켜야 붙음 |

- 주의: 출처가 있어도 AI 요약이 원문과 다를 수 있음. 무료판은 고급 검색 횟수 제한, Pro는 유료(요금 변동 가능).

**2. Perplexity (언어모델 평가 지표)** — 언어모델이 다음 단어를 얼마나 잘 예측하는지 나타내는 수. 낮을수록 좋은 모델. perplexity 10 ≈ 매번 10개 후보 중에서 고르는 정도로 헷갈림.
계산식: PPL = exp(−(1/N) Σ log p(단어ᵢ | 앞 단어들))

※ 학습 지식 기반 설명이며 최신 기능·요금은 바뀌었을 수 있음.
