1. PRJ 파일로 지도 홈페이지 만들기

요청 (2026-11-08)

@GRS80_UTMK.prj 해당 파일을 분석해서 지도 기반 홈페이지를 만들고 싶어

PRJ 분석 결과 - 이 파일은 EPSG:5179 (Korea 2000 / Unified CS, UTM-K)와 같은 정의입니다. - 서울시청(37.5665°N, 126.9780°E)을 넣으면 X 953,901.17, Y 1,952,032.08이 나옵니다. 파일 원문으로 계산해도, EPSG:5179 표준 정의로 계산해도 같은 값입니다.

항목 값 뜻
측지계 / 타원체 ITRF2000 / GRS80 (a = 6,378,137 m, 1/f = 298.257222101) 한국 측지계 2000. WGS84와 차이는 1 m 미만
투영 횡메르카토르(TM)
원점 38°N, 127.5°E 한반도 전체를 원점 하나로 처리
원점의 X, Y 1,000,000 / 2,000,000 m 좌표가 음수가 되지 않도록 더하는 값
축척계수 0.9996
단위 m

만든 것 - 지도: 아티팩트에서는 외부 지도 타일을 불러올 수 없습니다. 그래서 Natural Earth 해안선을 UTM-K로 투영해 캔버스에 직접 그렸습니다. - 지도 위 표시: UTM-K 격자, 휘어진 경위선, 중앙자오선, 원점, 주요 도시를 표시합니다. - 지도 조작: 클릭하면 핀이 찍히고 X·Y 좌표와 경위도가 나옵니다. 확대·축소와 이동이 되고, 화면 위치에 따라 축척 막대가 바뀝니다. - 좌표 변환: 경위도와 UTM-K를 서로 바꾸고, 여러 좌표를 한꺼번에 바꿔 엑셀용으로 복사할 수 있습니다. - PRJ 분석 탭: EPSG 코드를 자동으로 식별하고 매개변수를 해석합니다. 다른 .prj를 열면 그 좌표계로 다시 그립니다. - GeoJSON: 파일을 지도에 끌어다 놓으면 겹쳐 그립니다. - 배포: proj4js 2.9.0을 파일에 넣어 HTML 한 파일로 오프라인에서 동작합니다. - 커밋: 820d9dc UTM-K(EPSG:5179) 좌표 지도 홈페이지 추가. 초안 PR #107을 열었습니다.

3. 국토지리정보원 1:120만 shp 반영

요청

@kmap_2025_120_korean_shp.zip shp 파일로 올렸어

shp 분석 결과 - 파일은 국토지리정보원 대한민국 전도 1:120만(2025)이고, 12개 레이어입니다. - 12개 레이어의 .prj가 모두 Korea_2000_Korea_Unified_Coordinate_System이고, 매개변수가 처음 올린 PRJ와 같습니다. 그래서 좌표를 변환 없이 그대로 썼습니다. - 속성표(.dbf)는 CP949로 인코딩되어 있습니다.

4. 도로명으로 위치 찾기

요청 (shp 작업 도중)

도로명을 치면 위치를 확인할 수 있도록 만들고 싶어

만든 것 - 도로명·지명 검색: 고속국도·국도·지방도·철도·하천·지명·산·국립공원·시도·시군구·읍면동을 찾습니다. 숫자만 넣으면(예: 77) 국도 번호로 찾습니다. - 검색 결과: - 노선 전체를 강조합니다. - 구간 수와 길이(UTM-K 평면거리)를 보여 줍니다. - 노선 중앙의 좌표·경위도·행정구역과 지나가는 시도·시군구를 보여 줍니다. - 노선 버튼: 고속국도와 국도 번호를 버튼으로 고를 수 있습니다. - 지도 클릭: 시도·시군구·읍면동 주소와 가까운 도로 이름을 보여 줍니다. - 레이어: 레이어별로 켜고 끌 수 있고, 라이트·다크 테마를 지원합니다. - 한계와 보완: "세종대로" 같은 도로명주소의 거리 이름은 1:120만 데이터에 없습니다. - 그래서 shp(.shp + .dbf + .cpg/.prj)를 브라우저에서 직접 읽는 기능을 넣었습니다. - 도로명주소 전자지도의 도로구간 shp를 불러오면 그 도로명으로도 검색됩니다. - 시험용 shp(세종대로·테헤란로)로 확인했습니다. - 확인: Playwright로 1280px·400px 화면, 라이트·다크 테마에서 열어 봤습니다. 스크립트 오류는 없었고 가로 스크롤도 생기지 않았습니다. - 커밋: 39e9ad5 UTM-K 지도: 1:120만 shp 반영, 도로명·지명 검색 추가. 같은 아티팩트 주소에 갱신했습니다.

5. 지번주소로 위치 표시하는 방법

요청

지번주소를 치면 지도에서 위치는 표시하는 방법을 찾아줘

결론 - 정리한 문서는 docs/지번주소_위치표시_방법.html이고, 아티팩트도 따로 게시했습니다. - 브이월드·행안부 공식 문서 사이트는 이 작업 환경에서 접속이 막혀 직접 확인하지 못했습니다. API 파라미터와 한도는 기억 기준이라 구현 전에 확인이 필요합니다.

방법 필요한 것 정확도 건물 없는 땅 아티팩트에서 바로
A. 연속지적도 shp (추천) 시군구별 shp (무료) 필지 경계 찾음 됨
B. 브이월드 지오코더 API 인증키 필지 대표점 찾음 안 됨 (중계 필요)
C. 행안부 주소검색 + 좌표제공 API 인증키 2종 건물 출입구 못 찾음 안 됨 (중계 필요)
D. 카카오 로컬 API REST 키 대표점 대부분 찾음 안 됨 (중계 필요)
  • 방법 A의 원리:
  • 연속지적도의 PNU(19자리)는 법정동코드 10자리 + 산 여부 1자리 + 본번 4자리 + 부번 4자리입니다.
  • 동·리 이름으로 찾으려면 법정동코드 목록이 필요합니다.
  • 연속지적도는 대개 EPSG:5186이지만, .prj를 읽어 UTM-K로 변환합니다.
  • API 방식(B~D)의 제약: 아티팩트 페이지는 외부 주소로 요청을 보낼 수 없습니다. 이 세션, GitHub Actions, 작은 서버 중 하나가 API를 대신 불러야 합니다.
  • 커밋: 4e70fa1 지번주소 위치 표시 방법 비교 문서 추가
  • 남은 일: 연속지적도 shp를 올려 주시거나 쓸 API와 인증키를 정해 주시면 지번 검색을 구현합니다.
