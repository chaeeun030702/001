## 3. 반영 내용 — `[편집 9] 화면에서 바로 수정`

좌측 메뉴에 **관리 › 점검항목 편집** 화면 추가.

- 발주기관 / 시공사 / 하도급사 탭별 점검항목 목록(그룹·항목명·법적 근거·주기·증빙·상태).
- **수정**: 항목명, 그룹(목록 선택 또는 직접 입력), 점검주기(월·2개월·분기·반기·연·수시), 이행시기 설명, 증빙, 이행 방식, 양식명, 법적 근거(한 줄에 하나, `산업안전보건법 제64조…` 형식이면 국가법령정보센터 링크 자동 / 그 밖은 `이름 | https://주소`), 설명.
- **항목 추가 / 삭제 / 삭제 항목 되살리기 / 항목별 원래 내용으로 / 전체 원래대로**.
- 저장 즉시 체계도·점검표·검색에 반영(새로고침 불필요). 수정 내용은 localStorage `sapa-obl-edits-v1`에 보관.
- **편집 내용 내보내기 / 가져오기(JSON)**: 다른 PC·담당자와 수정 내용 공유.
- **편집 반영본 HTML 내려받기**: 수정 내용을 `<script type="application/json" id="obl-edits">`에 넣은 새 HTML 파일 생성 → 다른 PC에서 열어도 같은 항목으로 표시.
- 기존 점검 기록과의 연결: 기존 항목은 id를 그대로 유지하므로 입력한 점검결과가 이어짐. 새 항목 id는 `u{유형}{시간}` 형식으로 자동 생성.
- 파일 머리 주석에 `[편집 9]` 사용법 추가, CSS(`.edf`, `.edg`, `.eda`) 추가.

### 적용 방식(데이터 흐름)

```
OBL0 → (기존 보정 단계) → OBL, ALLOBL
                            │
                            ├─ OBLBASE = OBL 깊은 복사(원본 보관)
                            └─ applyEd(): OBLBASE + ED(mod/add/del) → OBL 재구성, ALLOBL 갱신
ED 우선순위: localStorage "sapa-obl-edits-v1"  >  HTML 안 <script id="obl-edits">  >  없음
```

## 4. 남은 일 / 주의

- **브라우저 동작 검증 미완료**(점검 스크립트 실행 중 중단됨). 아래 `t.js`로 확인 필요: 메뉴 전 화면 오류 없음, 수정·추가·삭제 반영, 새로고침 후 유지, 반영본 HTML 내려받기 후 다른 브라우저에서 반영, 모바일(390px) 가로 넘침 없음.
- `[편집 반영본 HTML 내려받기]`는 페이지를 읽은 시점의 DOM으로 원본을 다시 만들기 때문에, 소스 주석·공백 형식이 원본과 조금 다를 수 있음(동작에는 영향 없음).
- 항목을 수정하면 해당 유형 안에서 법령 순서 재정렬(`lawSort`)은 다시 하지 않고 그룹 순서만 다시 맞춤.
