---

## 1. 먼저, 이름부터 쪼개 볼까요?

`free-llm-api` = **free** + **LLM** + **API**

| 단어 | 뜻 | 비유 |
|------|----|------|
| **free** | 공짜 | 무료 |
| **LLM** | Large Language Model, 큰 언어 모델. ChatGPT·Claude·Gemini 같은 "말하는 AI"의 두뇌 | 책을 엄청 많이 읽은 똑똑한 친구 |
| **API** | 프로그램끼리 대화하는 창구 | 식당의 **주문 창구** (메뉴판을 보고 주문하면 음식이 나와요) |

👉 **"무료로 AI 두뇌를 내 프로그램에서 쓸 수 있는 방법"** 을 모아 둔 주제(토픽)예요.

---

## 2. GitHub '토픽'이 뭐예요?

GitHub는 코드를 올려 두는 거대한 **도서관**이에요.
'토픽'은 도서관의 **분류 스티커**예요. `free-llm-api` 스티커가 붙은 프로젝트들만 모아서 보여 줘요.
이건 하나의 프로그램이 아니라 **비슷한 프로젝트 56개를 모아 놓은 책장**이에요.

---

## 3. 왜 이런 게 필요할까요?

- ChatGPT 같은 AI를 **내 앱·게임·숙제 도우미 프로그램**에 넣고 싶다
- 그런데 API는 보통 **쓴 만큼 돈**을 내야 한다 💸
- 다행히 어떤 회사들은 **"조금까지는 공짜"** 로 열어 둔다 (무료 한도, 무료 티어)
- 그 **공짜 문이 어디 있는지** 찾아서 모아 둔 곳이 바로 이 토픽이에요.

> 🍦 비유: 아이스크림 가게 **무료 시식 코너**를 전부 지도에 표시해 둔 것과 같아요.
> 하루에 먹을 수 있는 양(한도)은 정해져 있어요.

## 5. 쉽게 그려 보는 동작 원리

```
 [내 앱/프로그램]
        │  "안녕, 오늘 숙제 도와줘!"  (API로 주문)
        ▼
 [게이트웨이(교통정리)]──→ A회사 무료 AI  (한도 다 썼네? ❌)
        │                └→ B회사 무료 AI  (여유 있음! ✅)
        ▼
   "네, 이렇게 풀면 돼요!" (답장)
```

## 6. 사용할 때 꼭 지켜야 할 것 🔐

1. **API 키 = 비밀번호!** 친구·인터넷에 올리면 안 돼요. 남이 내 한도를 다 써 버릴 수 있어요.
2. **무료에도 한도가 있어요.** 하루/1분에 보낼 수 있는 횟수가 정해져 있어요.
3. **출처를 확인하세요.** "무료 키 공유"라며 남의 키를 모아 놓은 곳은 불법이거나 위험할 수 있어요. 공식 가입으로 **내 키를 직접 발급**받는 게 안전해요.
4. **개인정보는 넣지 마세요.** 이름, 주소, 전화번호 같은 건 AI에게 보내지 않는 게 좋아요.
5. **나이 제한·약관**을 확인하세요. 서비스마다 가입 연령 규칙이 달라요.
6. **서비스는 갑자기 바뀌거나 사라질 수 있어요.** 무료가 유료로 바뀌기도 해요.
