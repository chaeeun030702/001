지번주소를 치면 지도에 위치 표시하기

UTM-K 좌표 지도(아티팩트)에 지번 검색을 붙이는 방법을 비교했습니다. 2026-11-08 작성.

결론

필지 경계까지 정확히 보려면 연속지적도 shp를 지도에 불러와 지번을 찾는 방법을 권합니다. 인터넷 API 없이 지도 페이지 안에서 바로 동작하고, 아티팩트의 보안 제한에도 걸리지 않습니다. 시군구 단위로 내려받아 쓰면 됩니다.

전국 어디든 지번 한 줄만 치면 나오게 하려면 지오코딩 API(브이월드·행안부 주소·카카오)가 필요합니다. 다만 아티팩트 페이지는 외부 API를 직접 부를 수 없으니, 중간에서 API를 대신 불러 줄 곳이 있어야 합니다. 이 Claude 세션이나 GitHub Actions, 작은 서버가 그 역할을 할 수 있습니다.

방법 비교

방법필요한 것정확도건물 없는 땅아티팩트에서 바로좌표계
A. 연속지적도 shp시군구별 shp 파일 (무료)필지 경계됨됨보통 EPSG:5186, .prj로 자동 변환
B. 브이월드 지오코더인증키 (무료)필지 대표점됨 (지번 검색 지원)안 됨 (중계 필요)요청할 때 좌표계 지정
C. 행안부 주소검색 + 좌표제공 API인증키 2종 (무료)건물 출입구건물 없으면 못 찾음안 됨 (중계 필요)UTM-K로 받음
D. 카카오 로컬 APIREST 키 (무료 한도)대표점대부분 됨안 됨 (중계 필요)WGS84 → UTM-K 변환

"중계 필요": 아티팩트 페이지는 보안 정책상 외부 주소로 요청을 보낼 수 없습니다. 페이지 대신 API를 불러 결과를 넘겨 주는 곳이 있어야 합니다.

방법 A

연속지적도 shp를 지도에 불러와 지번 검색추천

  • 받는 곳: 브이월드 오픈마켓·국가공간정보포털의 "연속지적도". 시군구별 shp로 받습니다. 파일 이름은 보통 LSMD_CONT_LDREG_시군구코드.shp입니다.
  • 들어 있는 정보: 필지 다각형과 PNU(19자리 필지고유번호), JIBUN(예: 123-4대).
  • PNU 구조: 법정동코드 10자리, 산 여부 1자리(1=일반, 2=산), 본번 4자리, 부번 4자리로 되어 있습니다. 예를 들어 "와우리 123-4"는 법정동코드 + 1 + 0123 + 0004입니다.
  • 검색 방식: 지번 숫자로 찾고, 같은 번지가 여러 동·리에 있으면 법정동코드 앞자리로 고르게 합니다.
    • 동·리 이름으로 고르려면 법정동코드 목록(행정표준코드관리시스템의 법정동코드 전체자료)이 필요합니다.
    • 이 목록을 페이지에 넣어 두면 봉담읍 와우리 123-4처럼 이름으로 칠 수 있습니다.
  • 좌표계: 연속지적도는 대개 GRS80 중부원점(EPSG:5186)입니다. 지도가 함께 들어 있는 .prj를 읽어 UTM-K로 바꿔 겹칩니다. 이 변환 기능은 이미 만들어 둔 shp 불러오기에 들어 있습니다.
  • 장점: 필지 경계를 강조하고 면적·지목까지 보여 줄 수 있습니다. 키나 인터넷이 필요 없습니다.
  • 한계: 시군구 하나도 수십 MB가 될 수 있습니다. 전국 단위로는 무겁습니다.
방법 B

브이월드 지오코더 API (주소 → 좌표)

  • 국토교통부 공간정보 오픈플랫폼의 API로, 지번주소(필지)와 도로명주소를 모두 좌표로 바꿉니다.
  • 요청 모양은 아래와 같습니다(기억 기준, 문서로 확인 필요). 
    https://api.vworld.kr/req/address?service=address&request=getcoord&version=2.0
  &type=parcel&crs=epsg:5179&format=json&key=인증키
  &address=경기도 화성시 봉담읍 와우리 123-4
  • type=parcel이 지번, type=road가 도로명입니다. crs로 결과 좌표계를 고를 수 있어 UTM-K로 바로 받을 수 있습니다.
  • 인증키는 무료지만 발급할 때 사용할 도메인이나 서비스를 등록합니다. 일일 호출 한도가 있습니다.
방법 C

행정안전부 주소검색 API + 좌표제공 API

  • 주소기반산업지원서비스(business.juso.go.kr)의 API입니다. 검색 API에 지번을 넣으면 도로명주소와 매칭된 결과를 줍니다.
  • 이 결과의 행정구역코드, 도로명코드, 지하여부, 건물본번·부번을 좌표제공 API에 넘기면 UTM-K 좌표(entX, entY, 건물 출입구 기준)를 줍니다.
  • 지도와 좌표계가 같아 변환이 필요 없습니다. 다만 도로명주소가 부여된 건물이 있는 지번만 찾을 수 있습니다. 논밭·임야 같은 빈 땅은 찾지 못합니다.
방법 D

카카오 로컬 API (주소 검색)

  • /v2/local/search/address.json?query=지번주소로 경위도(WGS84)를 받아, 지도의 proj4로 UTM-K로 바꿉니다.
  • 주소를 덜 정확하게 쳐도 잘 찾습니다. 상용 서비스라 이용약관과 일일 한도를 따라야 합니다.

API를 쓸 때 지도에 붙이는 구조

1. 입력지도 페이지에 지번 입력
2. 중계이 Claude 세션·GitHub Actions·작은 서버가 API 호출
3. 저장결과 좌표를 아티팩트 데이터(db)에 기록
4. 표시페이지가 좌표를 받아 핀 표시

한 번에 많은 지번을 처리할 때는 목록을 주시면 이 세션이 API로 일괄 변환해 지도 핀으로 넣는 방식이 가장 간단합니다. 이 경우 API 호스트를 이 작업 환경의 네트워크 허용 목록에 추가하고 인증키를 등록해야 합니다.

확인이 필요한 부분

이 작업 환경에서는 vworld.kr과 juso.go.kr 문서에 접속할 수 없어, 아래 항목을 공식 문서로 직접 확인하지 못했습니다. 구현 전에 확인하겠습니다.

  • 브이월드 지오코더의 정확한 파라미터 이름, 받을 수 있는 좌표계 목록, 일일 한도, 브라우저에서 직접 부를 수 있는지(CORS)
  • 행안부 좌표제공 API의 요청 필드 이름과 좌표 기준(출입구인지 건물 중심인지)
  • 내려받은 연속지적도 shp의 실제 필드 구성과 .prj 좌표계(지역·배포처마다 다를 수 있음)
