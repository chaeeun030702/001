### 1-3. 답변 요지 (당시 사용자에게 한 보고)

- 채용달력을 확인하지 못해 표 추가와 재게시는 하지 않았고, 기존 브리핑은 그대로 둠.
- 막힌 이유
  - 클라우드 세션이라 Chrome 확장 도구(`mcp__claude-in-chrome__*`)가 없음
  - 직접 접속도 네트워크 정책(프록시 403)으로 `calendar.saramin.co.kr` 차단 — 우회하지 않음
  - 대기업 신입 공채·'안전' 공고 목록은 지어서 채울 수 없음
- 진행하려면 둘 중 하나 필요
  1. 환경 설정(Edit)에서 Network access를 넓히거나 Custom + Allowed domains에 `calendar.saramin.co.kr` 추가
     (https://code.claude.com/docs/en/cloud-environments#network-access)
  2. 로컬 Chrome에서 10월·11월 달력 공고 텍스트/CSV를 붙여 넣기
