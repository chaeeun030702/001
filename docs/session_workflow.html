4수집 파이프라인 (safety_jobs/collect.py)

  1. 목록 수집
    출처마다 7분 한도, 실패해도 나머지 계속 (실패는 수집 현황에 기록)
  2. 사전 거르기
    목록에서 명백히 무관한 공고, '경력 n년'만 있는 공고 제외
  3. 상세 본문 + 이미지 읽기
    상세 22분 한도 · 지정 공고는 한도 무관 · 본문 이미지 공고당 4장 tesseract(한글) OCR → [이미지 본문], 캐시 ocr_cache.json
  4. 분석 · 선별 (keep)
    아래 규칙표 적용 · 지정 공고(user_pick)는 마감만 확인
  5. 중복 제거 · 이전 공고 이어받기
    상위 출처 우선 · carry_over 때도 규칙 재적용 · 본문 짧은 공고 다시 읽기
  6. 렌더 · 커밋
    latest.html/json/md, 날짜별 history, 신규 공고 메일 → 기준 브랜치 커밋
  7. 게시
    Claude가 latest.html을 브리핑 아티팩트에 같은 URL로 게시 (다른 세션 판과 충돌 시 내용 비교 후 병합)
