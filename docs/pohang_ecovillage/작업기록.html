## 편집과 인쇄

1. `index.html`을 브라우저로 연다.
2. **편집**을 누르고 글자를 바로 고친다. 사진을 누르면 다른 사진으로 바꿀 수 있다. 수정 내용은 브라우저에 자동으로 보관된다.
3. **HTML 저장**을 누르면 편집본이 HTML 한 파일로 저장된다. 저장한 파일도 다시 편집할 수 있다.
4. **A4 인쇄**를 누르면 A4 가로 12쪽으로 인쇄된다. PDF로 저장할 때는 여백을 '없음'으로 둔다.

build.py

"""template.html + img/*.jpg -> index.html (이미지를 data URI로 넣은 완전한 HTML 한 파일)."""
import base64
import pathlib
import re

here = pathlib.Path(__file__).parent
html = (here / "template.html").read_text(encoding="utf-8")


def embed(m):
    data = (here / "img" / f"{m.group(1)}.jpg").read_bytes()
    return "data:image/jpeg;base64," + base64.b64encode(data).decode()


out = re.sub(r"\{\{IMG_(\w+)\}\}", embed, html)
(here / "index.html").write_text(out, encoding="utf-8")
print("wrote", here / "index.html", len(out), "bytes")
