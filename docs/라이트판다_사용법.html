라이트판다(Lightpanda) 브라우저 쓰는 법

라이트판다는 화면이 없는 브라우저예요. 사람이 보라고 만든 게 아니라, 프로그램이나 AI가 웹사이트를 대신 돌아다니고 내용을 가져오라고 만든 브라우저입니다.

1. 라이트판다가 뭐예요?

크롬은 웹페이지를 예쁘게 그려서 보여 주는 화가라면, 라이트판다는 그림은 안 그리고 글과 구조만 재빨리 읽는 로봇이에요. 그림 그리는 시간이 없으니 훨씬 가볍고 빠릅니다.

이런 브라우저를 헤드리스(headless, 머리 없는) 브라우저라고 불러요. 화면(머리)은 없고 몸통만 일하는 거죠. 라이트판다는 크롬을 고쳐 만든 게 아니라 Zig라는 언어로 처음부터 새로 만들었어요.

2. 어디에 쓰나요?

  • 웹페이지 내용 뽑기 — 뉴스 기사, 상품 목록을 글(HTML·마크다운)로 저장
  • 반복 작업 자동화 — 버튼 누르기, 입력칸 채우기를 프로그램이 대신
  • AI 비서에게 웹 쓰게 하기 — Claude 같은 AI가 인터넷을 직접 돌아다니게 연결

3. 설치하기

명령어는 터미널(검은 창에 글자로 명령하는 프로그램)에 입력해요. 내 컴퓨터에 맞는 것 하나만 고르면 됩니다.

내 컴퓨터방법
맥(Mac)Homebrew 사용: brew install lightpanda-io/browser/lightpanda
리눅스아래 curl 명령으로 파일 내려받기
윈도우윈도우용은 없어요. WSL(윈도우 안의 리눅스)을 설치한 뒤 리눅스 방법을 따라 해요. 관리자 창에서 wsl --install
도커 사용자docker run -d --name lightpanda -p 127.0.0.1:9222:9222 lightpanda/browser:latest

  1. 리눅스(또는 WSL)라면 이 명령으로 내려받고 실행할 수 있게 만들어요.

    curl -L -o lightpanda https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-x86_64-linux && \
chmod a+x ./lightpanda

  2. 잘 깔렸는지 확인해요. 버전 번호가 나오면 성공!

    ./lightpanda version

./는 "지금 이 폴더에 있는 프로그램"이라는 뜻이에요. brew로 설치했다면 ./ 없이 lightpanda만 써도 돼요.

4. 쓰는 방법 네 가지

fetch 웹페이지 한 장 가져오기

이럴 때: "이 사이트 내용을 글로 저장하고 싶어"

./lightpanda fetch --obey-robots --dump markdown https://demo-browser.lightpanda.io/campfire-commerce/

--dump 뒤에 무엇을 쓰느냐에 따라 결과 모양이 바뀌어요.

html웹페이지 원본 코드
markdown읽기 쉬운 글 형태 (AI에게 주기 좋아요)
png > page.png그림 파일로 저장 (글자 위주로 그려져요)
pdf > page.pdfPDF 파일로 저장

--obey-robots는 "사이트 주인이 정한 규칙(robots.txt)을 지킬게요"라는 뜻이에요. 예의상 꼭 붙이세요.

serve 다른 프로그램이 조종하게 열어 두기

이럴 때: "내가 짠 코드로 브라우저를 움직이고 싶어" (코딩 조금 아는 친구용)

라이트판다를 대기 상태로 켜 두면, Puppeteer·Playwright 같은 도구가 9222번 문(포트)으로 접속해서 조종해요. 크롬용으로 짠 코드를 거의 그대로 쓸 수 있어요.

./lightpanda serve --obey-robots --host 127.0.0.1 --port 9222

그다음 자바스크립트에서 이렇게 연결해요.

import puppeteer from 'puppeteer-core';

// 라이트판다에 접속
const browser = await puppeteer.connect({ browserWSEndpoint: "ws://127.0.0.1:9222" });
const context = await browser.createBrowserContext();
const page = await context.newPage();

// 페이지를 열고 모든 링크 주소를 모으기
await page.goto('https://demo-browser.lightpanda.io/amiibo/', { waitUntil: "networkidle0" });
const links = await page.evaluate(() =>
  Array.from(document.querySelectorAll('a')).map(a => a.getAttribute('href')));
console.log(links);

await browser.disconnect();

agent 말로 시키기

이럴 때: "코딩은 몰라도 그냥 영어 문장으로 시키고 싶어"

AI(Claude, ChatGPT, Gemini 등)의 API 키가 있으면, 문장으로 일을 시킬 수 있어요. 브라우저가 알아서 페이지를 열고, 클릭하고, 정보를 찾아와요.

# 해커뉴스 1등 기사가 뭔지 물어보기
./lightpanda agent --task "top story on news.ycombinator.com?"

# 대화형으로 켜기 (API 키는 자동으로 찾아요)
./lightpanda agent

대화하다가 /save를 입력하면 지금까지 한 일을 대본 파일(.js)로 저장해요. 다음부터는 AI 없이 그 대본만 다시 돌리면 똑같이 움직여요. 돈(토큰)도 안 들어요.

./lightpanda run session.js

mcp AI 비서에 연결하기

이럴 때: "Claude 데스크톱이나 Claude Code가 라이트판다로 인터넷을 쓰게 하고 싶어"

MCP는 AI와 도구를 이어 주는 공용 콘센트 같은 거예요. AI 프로그램의 MCP 설정 파일에 아래 내용을 넣으면 끝이에요. /path/to/lightpanda는 내 컴퓨터에서 라이트판다 파일이 있는 실제 위치로 바꿔요.

{
  "mcpServers": {
    "lightpanda": {
      "command": "/path/to/lightpanda",
      "args": ["mcp"]
    }
  }
}

5. 알아 두면 좋은 주의사항

사용 기록 전송 기본으로 사용 통계(텔레메트리)를 회사에 보내요. 싫다면 실행 전에 export LIGHTPANDA_DISABLE_TELEMETRY=true 를 입력하세요.

  • 윈도우에서 바로는 안 돌아가요. 꼭 WSL 안에서 쓰세요.
  • 알파인(Alpine) 리눅스처럼 가벼운 리눅스에서는 실행이 안 될 수 있어요. 우분투 같은 일반 리눅스를 쓰세요.
  • 아직 "nightly(매일 새로 나오는 시험판)" 버전이라 어떤 사이트는 제대로 안 열릴 수 있어요.
  • 남의 사이트를 너무 많이, 빠르게 긁어 오면 민폐예요. --obey-robots를 붙이고 적당히 쓰세요.

낱말쉬운 뜻
