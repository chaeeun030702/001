② 비작업일수§1
  • A 기상 = Σ round(관측지점 값 × 적용률, 2) → 소수 1자리
  • B 법정공휴일 = 부록1 연·월 값
  • C 중복 = round_half_up(A × B ÷ 달력일수)
  • 적용 = max(A + B − C, 주40시간 하한 8일) → 정수 반올림
  • 동절기 중지월(12·1·2)은 그 달 전체 중지
  • 연속작업·준비·정리 달력은 비작업 0
③ 1일작업량§3-1·3-2
  • 수동입력 > DB지정 > 자동매칭 순
  • DB지정 — 번호·공종명·유사도 0.6
  • 자동매칭 — 규칙(정규식, 단위 일치) → 유사도 Dice ≥ 0.45
  • 보정계수 = 현장여건 × 공사규모 × 지질 × 기상기후 × 개별
  • 못 정하면 작업일수 0 + 경고, 임의로 채우지 않음
④ 작업일수§3-3
  • 단위작업 = ROUNDUP(수량 ÷ (1일작업량 × 보정계수 × 작업조))
  • 공정 W = Σ(작업일수 + 간접 + 보정) + 직접작업일수
  • 중복가능(운반·시험 등)은 합산 제외
  • 간접작업일수 — 공정 내 같은 패턴 1회
⑤ 주공정 CPM§2·§4
  • 가동률 달력 — 일별 가동률 누계 cum, finish / start_for_finish
  • 준비기간 P일 뒤가 공사 착수일
  • 전진 — FS(+lag)·SS(+lag 또는 n%)·FF → ES·EF
  • 후진 — LS·LF, 총여유 TF = LS − ES
  • TF ≤ 0 인 공정 = 주공정(Critical Path)
⑤-1 공기조정§5
  • 목표기간 초과 시에만 수행
  • 후보 ① 주공정 최대 작업일수 항목 작업조 +1
  • 후보 ② 선행 중첩 10%p씩 (FS → SS)
  • 후보마다 시험 계산해 최대 단축 채택
  • 최대 300회 · 연속 6회 무효 시 종료 · 최적 상태 복원
⑥ 종합§6
  • 총일수 = 정리기간 종료일차 + 1
  • 공사기간 = 준비 + 비작업 + 작업 + 정리
  • + 공사여건 보정일수
  • 개월 = 일수 ÷ 30.4167, 준공일 = 착공일 + (총일수 − 1)
⑦ 적정성§7
  • 부록5 산정공식 — B = Y + 준비 + 정리, 적용범위 밖은 참고
  • 동종공사 평균 개월 × 30.4167 (+ 준비·정리 가산)
  • 건설사업관리기간·환경공단 — 참고
  • 편차 = (A − B) ÷ B, ±20% 이내면 적정
  • 초과 시 원인 분석, 수치 조작 금지
