# 안전관리자 채용 일일 브리핑

매일 **19:07·19:27 KST** GitHub Actions(`.github/workflows/safety-jobs-briefing.yml`)가
`collect.py`로 아래 사이트의 안전관리자 채용 공고를 수집해 `briefings/`에 커밋하고,
**이틀에 한 번(짝수 날, 2·4·…·30일) 20:00 KST** Routine이 `briefings/latest.*`를 읽어 브리핑을 전달한다.
지난 보고일 이후 처음 수집된 공고는 **신규**(🆕, 초록 라벨·`N` 태그·신규 공고 표·필터)로 따로 표시한다.

```bash
uv run safety_jobs/collect.py --out briefings   # latest.md / latest.html / latest.json / YYYY-MM-DD.md
```

## 이전 수집 정보 유지

- 접수기한이 남은 공고는 다음 수집에서 목록에 안 보여도 `latest.json`에서 이어받는다(마감일 없는 공고는 14일).
- 실행마다 원격 최신 `briefings/`를 이어받아 수집하고, 결과는 `briefings/history/YYYY-MM-DD.json.gz`에 날짜별로 보관한다.

## 규칙

- **대상**: 안전 직무(안전·보건·HSE/EHS·소방·방재) 공고 중 신입 / 경력무관 / 신입·경력 / 인턴. 경력직 전용·마감 공고 제외.
- **직급**: 대리급 이상(제목·직급·본문·우대 표기 포함, 영문 Senior/Manager/Director 등)이 명시된 공고는 제외. 산업안전기사·건설안전기술사 등 기술사 우대 공고는 포함.
- **계약직**: 관심 기업(대기업 계열·외국계·코스피/코스닥·데이터센터/반도체) + 도급순위 15위 이내 건설사만.
- **제외 업체명**: 회사명(공백 무시)에 소방·조경·구조엔지니어링·감시단·재해예방·구조안전·세이프티·안전관리·학원·소방기술단·교육원·안전시스템·방재·무사퇴근·보건안전·호남산업이 있으면 제외(공공기관, 그리고 공단·공사·진흥원·기술원·연구원·안전원·재단으로 끝나는 이름은 제외하지 않음). 목록은 `collect.py`의 `EXCLUDE_CORP_TERMS`.
- **신입 초봉**: (업체명 정규화 일치 → 포함 관계·유사도 완화 매칭) 업체별 신입사원 초봉(잡코리아 기업 연봉정보, 기준 연도 표기)을 `구분 · 연봉` 칸에 함께 싣는다. `briefings/starter_salary.json`에 캐시(30일, 못 찾은 업체는 14일 뒤 재조회), 실행당 최대 160개사 새로 조회.
- **선택 삭제**: 브리핑 페이지 표 맨 왼쪽 체크 칸(머리글은 전체 선택)을 고르고 `선택 삭제` → 같은 자리의 `제외 확정`을 누르면 페이지 공유 DB(`excluded`)에 기록된다(`취소`·Esc로 취소). 보고 Routine이 수집 전에 이를 `safety_jobs/excluded.json`으로 옮기고, 수집기는 해당 URL·업체+공고명을 다음 리포트부터 제외한다(‘제외한 공고 N건 · 되돌리기’에서 되돌리기).
- **신입 초봉 웹 조사**: `safety_jobs/starter_manual.json`에 인터넷에서 확인한 초봉(출처·기준연도)을 두면 잡코리아 수집값보다 우선한다. `suppress: true`는 근거를 확인 못 한 수집값을 숨긴다.
- **복지 표시**: 공고 본문에 자녀학자금·노동조합(노조)·주택지원(주택자금·사택·주거지원)·기숙사가 명시되면 공고명 아래 라벨로 표시, `복지` 필터·지표 제공.
- **사람인 직접 추가**: 다른 세션이 사람인에서 직접 찾은 공고는 `manual_postings.json`에 `"source": "사람인"`, `"safety_job": "yes"`(직무 확인이 필요하면 `"check"`), `"added"`(찾은 날)로 넣는다. 사람인 공고로 싣고 상세 본문도 읽으며, 사용자 삭제·중복 규칙은 그대로 적용한다.
- **LinkedIn**: 브라우저 예약 작업이 브리핑 DB `manual` 컬렉션에 넣은 `linkedin-*` 공고를 `manual_postings.json`에 `"source": "LinkedIn"`으로 옮겨 싣는다. 수집기는 LinkedIn에 접속하지 않고(상세 본문 조회 없음) 넘겨받은 직무·고용형태·메모만 쓰며, 외국계로 분류한다.
- **공고 표 묶음**: 사람인에서 오늘 처음 찾은 공고는 `신규 공고`에만 싣고, 나머지는 `[정규직]`·`[계약직]`·`[고용형태 미표기]`(인턴은 `[인턴]`)로 나눈다. 대기업 신입 공채는 별도 칸 없이 `[정규직]`에 `대기업 신입 공채` 배지로 싣고(계약직·인턴 공고는 해당 묶음), 직무 확인 필요 공고도 별도 칸 없이 고용형태 묶음에 `직무 확인 필요` 배지와 사유를 붙여 싣는다.
- **담당 업무 기준**: 제목에 안전·보건·HSE 직무가 없는 공고는 상세 본문의 담당 업무(주요 업무·업무 내용·모집 분야) 항목에 '안전'(보건관리·산업위생·HSE·EHS·Safety 포함)이 있을 때만 싣는다. 담당 업무에 안전이 없으면 `담당 업무에 안전 없음`으로 제외하고, 항목을 읽지 못하면 `직무 확인 필요`로 남긴다. '안전수칙 준수'·'안전하게'·정보보안 같은 표현은 안전 업무로 보지 않는다.
- **직무 확인 필요**: 관심 기업(대기업 계열·외국계·상장·시평 100위·공공기관) 공고 중 안전 키워드에 걸렸지만 안전 직무로 확정되지 않은 공고, 건설·에너지·화학 공채는 버리지 않고 `직무 확인 필요` 칸에 싣는다. 다른 브리핑·캐치 달력에서 넘겨받은 공고는 `safety_jobs/manual_postings.json`에 넣는다.
- **중복**: 업체명 + 제목 유사도로 판단, 위쪽 사이트 것을 남긴다.
- **표기**: `[정규직]`, `[계약직]`, `[인턴]`, `[고용형태 미표기]` 문단으로 나눈다.
- **표 열**: 구분 · 업체명 · 공고명 · 지원 자격(학과·자격·영어·학력) · 우대 사항 · 접수기한 · 출처.
- **강조**: 🔴 데이터센터·하이테크·삼성·하이닉스 관련 / 🔵 대기업군·외국계 (둘 다면 🔴).
  HTML(`latest.html`)은 행 배경색으로 구분한다.

지원 자격·우대 사항은 상세 페이지 본문에서 자동 추출한 요약이므로 지원 전 원문 확인이 필요하다.
