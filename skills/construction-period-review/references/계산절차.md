# 계산절차 — 프로그램 없이 Claude가 직접 수행하는 공사기간 산정

원본 Python 엔진(`cpa/`)이 하던 일을 Claude가 **이 문서와 `기준값.md`, `data/*.json`만으로** 수행하도록 다시 쓴 절차서다.
`cpa` 패키지를 가져오거나 실행하지 않는다. 사람이 엑셀로 검토하듯 단계별로 계산하고, 매 단계 결과를 표로 남긴다.

- 계산이 길면 **검산용 임시 스크립트**(스크래치 폴더, 이 문서의 식을 그대로 옮긴 것)를 써도 된다. 단, 입력은 `data/*.json`·사용자 자료뿐이고 결과는 항상 이 문서의 식과 일치해야 한다.
- 수치를 지어내지 않는다. 판단값(보정계수·수동 1일작업량·직접작업일수)은 근거를 비고에 적는다.
- 반올림 규칙: `round_half_up(x)` = x≥0이면 floor(x+0.5). (파이썬 기본 반올림이 아님. 2.5→3)
- 달력일 환산: 1개월 = 365/12 = 30.4167일. 월 표기는 일수÷30.4167.

## 1. ② 비작업일수 (월별)

월·프로필별로 다음을 계산한다 (`days`=그 달의 달력일수).

1. 프로필의 각 조건 c(적용률 w≠0): `값(c)` = c≤13이면 `stations[지점].cond[c][월-1]`, c=14면 미세먼지[월-1], c=15면 사용자정의[월-1].
   `A_c = round(값(c) × w, 2)`, **A = round(ΣA_c, 1)**
2. **연속작업**(법정공휴일 미적용) 프로필 또는 **준비·정리** 달력: A=B=C=0, 적용 비작업일수=0. (동절기 중지가 켜져 있고 그 달이 중지월이며 제외 프로필이 아니면 적용=days)
3. B = 법정공휴일수 `holidays.json`의 `data[연도][월-1]` (연도가 없으면 가장 가까운 연도의 같은 달).
4. **C = round_half_up(A × B ÷ days)** (정수), **소계 = round(A + B − C, 1)**
5. **적용 = max(소계, 주40시간 하한 8)**; 정수반올림=Y이면 적용 = round_half_up(적용).
6. 동절기 중지 반영 중이고 그 달이 중지월이며(제외 프로필 아님) → 적용 = days (그 달 전체 중지).
7. 작업가능일수 = max(days − 적용, 0), **가동률 = 작업가능일수 ÷ days**.

연간 기상 비작업(표 2-5): 프로필별 각 조건 `round(값×w,1)`의 12개월 합.

## 2. 가동률 달력 (공정별 작업일수 → 달력 종료일)

착공일을 0일차로 두고, 하루마다 그날이 속한 월의 가동률(위 7)을 그 프로필에 대해 더해 누계 `cum[i]` = 0~(i−1)일차 작업가능일 합계를 만든다. (프로필마다 따로, 최대 15년)
- **finish(프로필, 착수일차 s, 작업일수 W)**: W≤0이면 s−1. 아니면 `cum[e] ≥ cum[s] + W`(−1e-9)인 **가장 작은 e**를 찾아 종료일차 = e−1 (포함). 범위를 넘으면 "15년 초과" 오류.
- **start_for_finish(프로필, 종료일차 f, W)**: W≤0이면 f+1. 아니면 `cum[s] ≤ cum[f+1] − W`(+1e-9)인 **가장 큰 s**, 단 0≤s≤f로 제한.
- 의미: 가이드라인 제2장 3.(3) "개시일부터 월별 작업가능일수를 차감해 가며 종료일 산정(마지막 달은 비례)"과 같다.

## 3. ③ 1일작업량 결정과 ④ 작업일수

### 3-1. 1일작업량 결정 순서
1. **수동입력**(품셈·실적) 값이 있으면 그것(근거를 비고에).
2. **DB지정**: 숫자면 `productivity_db.json`의 `no`, 문자열이면 공종명 정확 일치, 아니면 공종명 Dice(바이그램) 유사도 ≥0.6인 최고 항목. 못 찾으면 경고 후 3번.
3. **자동매칭**: (가) `기준값.md` §10 규칙(공종명+규격 정규식)이 일치하고 DB 항목 단위=수량 단위 → 채택. (나) 아니면 같은 단위(정규화 후)의 DB 항목 중 `Dice(공종명+규격, DB공종명+DB조건)` 최고점이 **≥0.45**이면 유사도매칭, 미만이면 "매칭불가(최고유사도 …)".
   - Dice(a,b) = 2·|바이그램(a)∩바이그램(b)| ÷ (|a의 바이그램|+|b의 바이그램|). 바이그램은 공백·`()[],·./-_~` 제거 후 문자 2-gram 집합.
4. DB 단위가 수량 단위와 다르면 "단위불일치" 경고. 1일작업량이 끝내 없으면 **작업일수 0 + 경고**(중복가능 행은 "작업일수 미합산"으로 정상 처리). 미결정 수량은 임의로 채우지 말고 DB지정·수동입력을 요청한다.
- DB 항목 필드: `no, field, group, name, condition, rate, unit, source, display, note` (rate = 1일 작업량, unit = `…/일`).

### 3-2. 보정계수
`보정계수 = 현장여건 × 공사규모 × 지질조건(해당 공종만) × 기상기후(옥외·구조물 프로필만) × 개별보정계수` → 소수 4자리 반올림. (표는 `기준값.md` §3)

### 3-3. 단위작업 작업일수 (④)
```
적용작업량 = 1일작업량(DB 또는 수동) × 보정계수
원시일수 = 수량 ÷ (적용작업량 × 작업조)         (수량 0이면 0)
작업일수 = ROUNDUP(원시일수)                      (정수일 단위, 최소 1일; 산정단위 0.1일이면 0.1 단위 올림)
```
- 작업조는 소수 허용(구간분할 배수 등).
- 단위작업 합계 = (중복가능=Y이면 0, 아니면) 작업일수 + 간접작업일수 + 보정일수.
- **공정 작업일수 W = Σ 단위작업 합계 + 직접작업일수.** W=0인 공정은 마일스톤으로 처리(경고).
- 간접작업일수 자동: `기준값.md` §8 규칙을 공정 내 같은 패턴 1회만. 입력값이 있으면 입력값 우선.

## 4. ⑤ 주공정 CPM (공정별 가동률 달력 위)

### 4-1. 준비기간
준비기간 P일은 비작업일 미계상(달력일). 단 동절기 중지 반영 시 중지월은 건너뜀 → `prep_end = finish(준비정리, 0, P)` (P=0이면 −1). **공사 착수일차 = prep_end + 1.**

### 4-2. 전진계산 (위상정렬 순서)
각 공정 a에 대해 `es = 착수일차`(또는 `snet` 착수가능일이 더 늦으면 그 일차)에서 시작하여 선행관계마다 갱신:
- **FS(+lag)**: `es = max(es, p.ef + 1 + lag)`
- **SS+lag**: `es = max(es, p.es + lag)` / **SS n%**: `pt = finish(p.프로필, p.es, p.W × n) + 1` (p.W=0이면 p.es), `es = max(es, pt + lag)`
- **FF+lag**: `ff_req = max(ff_req, p.ef + lag)` — 모든 선행을 본 뒤 W>0이면 `finish(a.프로필, es, W) < ff_req` 일 때 `es = max(es, start_for_finish(a.프로필, ff_req, W))`
- 결과: `ef = finish(a.프로필, es, W)` (W=0이면 es−1). 전체 종료 `finish = max(ef)`.
- 위상정렬 중 선행 공정이 없거나 순환이면 오류.

### 4-3. 후진계산 (역순)
`lf = finish`(전체 종료)에서 시작, 각 후속 s와의 관계마다:
- FS: `lf = min(lf, s.ls − 1 − lag)`
- SS n%: `후보 ls = start_for_finish(a.프로필, s.ls − 1 − lag, W×n)` (W=0이면 `s.ls − lag`) → `ls_cap = min(ls_cap, 후보)` / SS(+lag): `후보 = s.ls − lag`
- FF: `lf = min(lf, s.lf − lag)`
- W>0이면 `ls = start_for_finish(a.프로필, lf, W)`; `ls_cap < ls`이면 `ls = ls_cap, lf = finish(a.프로필, ls, W)`. W=0이면 `ls = lf+1`(ls_cap 있으면 `min(lf+1, ls_cap)`).
- **총여유 TF = ls − es. TF ≤ 0이면 주공정(Critical).**

### 4-4. 공사기간·구성
- **주공정(CP)** = TF≤0이고 W>0인 공정을 (es, ef) 순으로 나열한 것.
- 정리기간: `end = finish(준비정리, finish+1, 정리일수)` (정리=0이면 end=finish). **총 공사기간(일) = end + 1.**
- 개월 = 총일수 ÷ 30.4167. 준공일 = 착공일 + (총일수 − 1).
- 구성 분해(주공정 기준, 일별): 공사 구간 d=착수일차…finish에서 그날 진행 중인 주공정 공정 중 **그날 가동률이 가장 높은 공정**의 가동률을 c로 쓴다(진행 공정이 없으면 c=1, 단 동절기 중지월이면 0). `비작업 += 1 − c` (동절기 중지로 c=0이면 중지일로 센다). **작업일수(주공정) = 공사구간일수 − 비작업 − 공사구간 내 동절기 중지일.** 준비·정리 구간에서 동절기에 멈춘 일수도 중지일에 합산.
- 동절기 달력일수 = (중지 반영 시) 전체 기간 중 중지월에 속한 일수.
- 구성 표기: `공사기간 = 준비 + 비작업 + 작업 + 정리 (+ 동절기 중지)`.

## 5. ⑤-1 공기조정 (목표기간 초과 시)

목표기간(일): 발주처요구 = round(개월×30.4167), 준공예정일 = (준공예정일 − 착공일)+1, 건설사업관리기간 = round(`기준값.md` §6 보간개월 × 30.4167), 없음 = 생략.
- 기본 산정 ≤ 목표 → 조정 불필요. 초과 시 **탐욕 반복(최대 300회)**:
  1. 후보 수집 — (a) **작업조 증원**: 주공정 공정의 단위작업 중 `중복가능 아님·1일작업량 있음·작업조<최대작업조·작업일수>1`인 것 중 작업일수가 가장 큰 항목 작업조 +1. (b) **공정 중첩**: 최대중첩률>0인 공정의 각 선행 중 선행이 주공정이고 FF가 아닌 것에 대해 현재 중첩률(FS=0, SS n% → 1−n)을 10%p 올린 값이 최대중첩률 이하이면 `SS(1−새중첩률)%`로 변경.
  2. 각 후보를 시험 적용해 총 공사기간을 재계산하고, **(단축일수 큰 순, 작업조 우선, 주공정 작업일수 합 작은 순)**으로 하나 채택, 이력 기록(단계·구분·조치·전후 일수·단축).
  3. 최고 기록(최소 총일수)을 보관. 총일수가 목표 이하가 되면 종료. 후보가 없거나 연속 6회 단축이 없으면 종료.
  4. 종료 후 **최적 상태로 복원**(효과 없던 후속 조치는 버림), 일정 재계산.
- 목표 미충족이면 경고: "목표기간 이내로 조정 불가(최소 X일) — 목표기간 재검토 또는 공법·작업시간 조정 필요". `공기조정 결과 채택=N`이면 기본안을 최종으로 두고 조정안은 참고.

## 6. ⑥ 종합
`최종 공사기간 = (채택 일정 총일수) + 공사여건 보정일수`, 준공일 = 착공일 + (총일수 − 1).

## 7. ⑦ 적정성 검토 (허용범위 ±20%)

비교용 A = 최종 공사기간 − (동절기 공사중지 반영 시 공사기간 내 동절기 달력일수; 부록5 실적공기는 동절기 중지 미포함이므로). 편차 = (A − B) ÷ B, |편차| ≤ 허용범위이면 적정.
1. **부록5 산정공식**(시설유형이 있을 때): 필요 변수가 비면 "산정 불가". 있으면 `Y` = 공식(§5), `B = Y + 준비 + 정리`. 총공사비가 적용범위 안이면 **주기준**, 밖이면 판정에 `(참고)`.
2. **동종공사 실적**(사례가 있을 때): 평균개월 × 30.4167 = Y, `B = Y + (가산=Y이면 준비+정리)`. 주기준.
3. **건설사업관리기간**(항상, 참고): B = 보간개월 × 30.4167.
4. **환경공단 산정식/경험치**(선택, 참고): 산정식은 `Y(식) + 준비 + 정리`, 경험치는 공사비(억원) 구간의 개월 × 30.4167.
- **종합판정**: 주기준 행만 본다. 판정기준 `부록5`/`동종공사`면 해당 행만. `모두`면 전부 ±20% 이내여야 적정, 그 외(자동)는 **하나라도** 이내면 적정(일부 초과 시 "적정(일부 기준 편차 초과 — 사유 검토)"). 주기준이 없으면 "판정불가(비교기준 없음)".
- 초과 시 원인(시설 특성·사례 규모 차이·입력 오류)을 분석해 서술에 반영하거나 입력을 고친다. **결과를 맞추려고 근거 없이 수치를 조작하지 않는다.**

## 8. 월별 비작업일수표·공정률 (보고서용 집계)
- **월별표**(착공월~준공월): 각 월의 준비일수(d<공사착수), 정리일수(d>finish), 공사일수, **지배 프로필**(그달 공사일 중 최다 프로필), 그 프로필의 A·B·C·소계·적용·작업가능·가동률, 반영 비작업=Σ(1−그날가동률), 반영 작업=공사일수−반영비작업. 구분 표기 = 준비·공사(또는 시운전)·정리.
- **월별 공정률**: 가중치(없으면 W)로 가중, 각 공정을 [es,ef] 동안 균등 배분해 월별 비율과 누계(최대 100%).
- **분야·대공정 집계**: (분야, 대공정)별 공정명 목록, 작업일수 합, 주공정 포함 여부.

## 9. 추가검토 — 동절기 공사중지 반영 시 일정
`동절기 공사중지`가 `추가검토`이면: 같은 입력으로 **동절기 중지를 켜서**(중지월 12·1·2월, 제외 프로필 제외) §1~§4를 한 번 더 계산한다 (공기조정 결과 일정 기준). 보고: 총일수·개월·준공일·(+기본안 대비 증가일수)·동절기 달력일수·동절기 제외 시 공사기간. `반영`이면 처음부터 §1~§7을 중지 반영으로 계산(§7 비교용 A에서 동절기 달력일수 제외).

## 10. 수량첨부 검토 — 수량파일에서 입력서식 만들기

### 10-1. 공정 선택

### 10-2. 수량파일 해석 (엑셀 시트별)
1. 위쪽 40행 안에서 **머리글 행**을 찾는다(2단 머리글이면 위·아래 행을 합쳐서). 공백·`·`·`_` 제거 후 비교:

3. 머리글을 못 찾는 시트·행이 없는 시트는 건너뛰고 사용자에게 알린다.
