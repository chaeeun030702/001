# 산출물 작성 — 수정·편집 가능한 A4 세로 HTML 4개

계산(`계산절차.md`)이 끝나면 아래 **4개 파일을 각각** 만든다. 모두 `html_template.html`을 복사해 `{{문서제목}}`·`{{작성일}}`·`{{본문}}`만 채운다(스타일·편집·저장·인쇄 버튼은 템플릿에 들어 있음).
- 형식: HTML 한 파일, **A4 세로**(`@page size: A4 portrait`), 본문 `contenteditable`, [편집 켜기/끄기]·[저장(HTML)]·[인쇄/PDF]. 그림은 `<img src="data:…">` 또는 인라인 SVG로 파일 안에 넣는다(외부 파일·CDN 금지).
- 표: 머리글 행은 `<th>`, 숫자 칸은 `class="num"`. 열이 10개 넘으면 `<table class="w2">`, 20개 넘으면 `class="w3"`(글자 축소)로 A4 폭에 맞춘다.
- 쪽 나눔: 장·부록·시트 사이는 `<div class="pb"></div>` 또는 `<section class="sheet">`.
- 수치는 계산 결과 그대로 옮긴다(HTML에서 숫자를 고치려면 입력을 고쳐 다시 계산). 문장·서술은 사용자가 HTML에서 직접 고쳐도 된다.
- 파일 위치: `output/<사업명>/`. 사용자에게는 4개를 각각 보낸다.

## 1. `01_공사기간산정보고서.html` — 공사기간 산정보고서
표지(사업명·보고서 제목·「적정 공사기간 확보를 위한 가이드라인(2026, 국토교통부)」 기준 적정성 검토·작성년월·발주청)·목차 → 본문:
- **제1장 사업의 개요**: 1.1 사업의 개요(1.1.1 목적, 1.1.2 개요 표, 1.1.3 추진경위) / 1.2 사업의 주요내용(1.2.1 주요 시설·공사내용, 1.2.2 분야별 공정 구성 표)
- **제2장 공사기간 산정**
  - 2.1 법적근거 및 산정기준(가이드라인·고시 제2024-1021호)
  - 2.2 공사기간 산정: 2.2.1 공사특성, 2.2.2 가이드라인에 따른 공기산정(준비기간·비작업일수 A+B−C 월별표, 1일작업량 적용, 작업일수 집계, CPM·주공정, 공사기간 구성 표), 2.2.3 목표기간 대비 조정 검토(조정이력 요약, 해당 시)
  - 2.3 적정성 검토: 2.3.1 부록5 산정공식, 2.3.2 동종·유사공사, 2.3.3 건설사업관리기간(참고), 2.3.4·2.3.5 환경공단(참고), 2.3.6 적정성 판정(기준별 B·편차·판정, 종합판정)
  - 2.4 공사기간 결정(최종 일수·개월·착공~준공일, 동절기 추가검토 결과)
- **제3장 예정공정표**: 3.1 주공정(Critical Path) 공정표(막대공정표를 인라인 SVG로: 주공정=녹색 막대+적색 화살표, 비주공정, 총여유 TF, 마일스톤, 월별 공정률 곡선), 3.2 시공조건 명시 및 유의사항

## 2. `02_보고서부록.html` — 보고서 부록
표지·부록 목차 → 부록 1~11 (각 부록마다 쪽 나눔):
1 법정 공휴일수(연도×월 표, `holidays.json`) / 2 작업제한 기상조건 및 기상프로필 설정 / 3 관측지점 기상조건별 비작업일수 및 월별 산정표(조건 1~14 월별 + 월별 A·B·C·적용 표) / 4 1일 작업량 적용내역(DB 번호·공종·조건·1일작업량·단위·출처) / 5 작업일수 산정 세부내역(공식 `ROUNDUP(수량÷(1일작업량×보정계수×작업조))=N` 포함) / 6 CPM 계산표(ES·EF·LS·LF·TF·CP) / 7 공사기간 조정 이력(단계·구분·조치·전후·단축) / 8 적정성 검토 산정근거(부록5 공식 표 포함) / 9 동절기 공사중지 추가검토 / 10 시공조건 명시 항목 예시(가이드라인 부록6) / 11 검토 작업경과(단계별 로그)

## 3. `03_검토과정_워크북.html` — 검토과정 워크북 (확인용)
시트마다 한 절(`<section class="sheet">`): 0 작업경과 / ① 공사개요 / ②-1 기후 비작업 근거 / ② 비작업일수(월별 A·B·C·적용·가동률) / ③ 1일작업량 매칭(자동·유사도·수동·DB지정, 신뢰도, 경고) / ④ 작업일수 산정 / ⑤ CP 구성(ES·EF·LS·LF·TF) / ⑤-1 공기조정 / CP 공정표 / ⑥ 공사기간 종합 / ⑦ 적정성 검토 / 추가검토(동절기) / 부록1 법정공휴일. 각 절에 계산식과 입력값을 함께 적어 사용자가 과정을 추적할 수 있게 한다.

## 4. `04_입력.html` — 입력
0 사용안내 / 1_공사개요(항목·입력값·설명 3열 표) / 2_비작업조건(프로필×조건 적용률, 미세먼지 월별) / 3_수량(공정ID·공종·규격·단위·수량·DB지정·수동1일작업량·작업조·간접·보정·중복가능·비고) / 4_공정(공정ID·분야·대공정·공정명·기상프로필·직접작업일수·선행공정·최대중첩률·가중치…) / 5_유사사례 / (수량첨부 검토 시) 6_제외수량(미반영 수량과 사유). 입력 칸은 노란 배경(`background:#fff2cc`)으로 표시해 사용자가 바로 고칠 수 있게 한다.
