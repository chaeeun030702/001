# 자기소개서 자동 작성 (안전관리자 정규직)

매일 **20:47 KST** Routine이 안전관리자 채용 브리핑(`briefings/latest.json`)에서
아래 조건의 공고를 골라 이 폴더에 자기소개서 초안을 쓴다.

| 조건 | 내용 |
|---|---|
| 기업 | 🔵 대기업 계열 · 🌐 외국계 · 코스피 · 코스닥 상장사 (채용 달력 관심 기업) |
| 고용형태 | 정규직 |
| 시점 | 접수 마감 **10일 전(D-10)**. 그보다 늦게 처음 수집된 공고는 수집 다음 날 바로 |
| 중복 | 폴더 안에 같은 `공고 URL:` 이 적힌 초안이 있으면 다시 쓰지 않는다 |

대상 선정: `python3 safety_jobs/cover_letters.py --briefing briefings/latest.json`

## 원본

초안은 [`원본_현대건설_신입사원_자기소개서.md`](./원본_현대건설_신입사원_자기소개서.md)의
경험·역량·자격만 근거로 쓴다. 원본에 없는 경험·수치·수상은 지어내지 않고 `[직접 입력: …]` 로 남긴다.
원본은 claude.ai 프로젝트 **claude 자기소개서**의 현대건설 신입사원 자기소개서를 옮겨 둔 것이다
(자동 작업은 claude.ai 프로젝트를 직접 읽을 수 없다). 프로젝트 쪽을 고치면 이 파일도 함께 갱신한다.

## 초안 형식

파일명 `YYYY-MM-DD(마감일)_업체명_공고명.md`

```
# {업체명} — {공고명}
- 공고 URL: {url}
- 접수 마감: {YYYY-MM-DD} (작성일 기준 D-n)
- 구분: {대기업 계열/외국계/코스피/코스닥} · 정규직 · {신입/경력무관…}
- 지원 자격 / 우대 사항: {브리핑 요약}
- 작성일: {YYYY-MM-DD} · 상태: 초안 (원문 문항 확인 필요)

## 1. 지원 동기 (700자 내외)
## 2. 직무 역량과 경험 (1000자 내외)
## 3. 안전관리 경험·가치관 (700자 내외)
## 4. 입사 후 포부 (700자 내외)

## 원본에서 가져온 소재 / 보완할 점
```

공고 원문에 문항이 있으면 그 문항·글자 수를 따른다. 지원 전 반드시 원문 문항과 대조해 고친다.
