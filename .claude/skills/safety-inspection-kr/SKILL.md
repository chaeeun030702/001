# 한국형 건설 안전점검 스킬 (safety-inspection-kr)

대한민국 **산업안전보건법령**과 **중대재해처벌법**, KOSHA 기준에 맞춘 건설현장
안전관리 스킬이다. 미국 OSHA(29 CFR 1926) 기반의 DDC 안전 스킬과 달리 **국내
법령·용어·기준**을 사용한다.

> ⚠️ **법령 고지**: 아래 조문 번호와 수치는 일반적으로 통용되는 국내 기준을 정리한
> 것이다. 산업안전보건법령은 자주 개정되므로, 실제 문서·보고에 사용하기 전에
> **국가법령정보센터(law.go.kr)의 최신 법령**과 **KOSHA 최신 지침**으로 반드시
> 대조·검증한다. 법적 판단이 필요한 사안은 안전관리자·노무사·전문가 확인을 거친다.

## 언제 사용하는가

- 국내 건설현장 **안전점검 체크리스트** 생성·수행·기록
- **위험성평가**(유해·위험요인 파악 → 위험성 추정 → 감소대책) 문서 작성
- **산업재해 / 중대재해** 발생 시 보고 대상 여부 판정 및 보고서 초안
- **TBM(Tool Box Meeting, 작업 전 안전점검회의)** 자료 생성
- 국내 규정 근거(조문) 인용이 필요한 안전 문서 작성

산출물을 hwpx 공문/보고서나 pptx로 만들어야 하면 해당 형식 스킬과 함께 사용한다.

## 작업 순서

1. **대상·범위 확인** — 공종(굴착·비계·철골·전기·양중 등), 작업 높이, 밀폐공간
   여부, 상시근로자 수(중대재해처벌법 적용 판단), 원·하청 구조를 확인한다.
2. **규정 근거 확인** — `references/regulations-kr.md`에서 해당 위험요인의 국내 조문·
   기준을 확인한다.
3. **스크립트 실행** — 목적에 맞는 스크립트를 실행한다(아래 표). 파이썬 표준
   라이브러리만 사용하며 외부 설치가 필요 없다.
4. **검토·보정** — 생성물을 최신 법령·현장 상황에 맞게 검토하고, 미확정 항목은
   추정하지 말고 표시한다.

## 스크립트

경로는 이 스킬 디렉터리 기준이다.

| 스크립트 | 용도 |
|---|---|
| `scripts/checklist_kr.py` | 공종별(공통·추락·비계·굴착·전기·밀폐공간·화기 등) **안전점검 체크리스트**를 안전보건규칙 조문과 함께 생성 |
| `scripts/incident_kr.py` | 사고 정보를 입력하면 **산업재해 보고 대상**·**중대재해(산안법)**·**중대산업재해(중대재해처벌법)** 해당 여부와 **보고 기한·방법**을 판정 |

TBM(작업 전 안전점검회의) 브리핑이 필요하면 `checklist_kr.py --category <공종> --tbm` 로 요약본을 생성한다.

실행 예시:

```bash
python3 scripts/checklist_kr.py --category 추락          # 추락 위험 점검표
python3 scripts/checklist_kr.py --category 공통 --format md
python3 scripts/incident_kr.py --deaths 1                # 중대재해/보고 판정
python3 scripts/incident_kr.py --hospital-6m 2           # 6개월 이상 부상 2명
```

## 국내 핵심 기준 요약 (상세는 references/regulations-kr.md)

### 중대재해(산업안전보건법 시행규칙 제3조)
다음 중 하나에 해당하면 **중대재해**로, 발생 시 관할 지방고용노동관서에 **지체 없이**
(전화·팩스 등) 보고한다.
1. 사망자 **1명 이상**
2. 3개월 이상의 요양이 필요한 부상자 **동시 2명 이상**
3. 부상자 또는 직업성 질병자 **동시 10명 이상**

### 중대산업재해(중대재해처벌법 제2조)
1. 사망자 **1명 이상**
2. 동일한 사고로 6개월 이상 치료가 필요한 부상자 **2명 이상**
3. 동일한 유해요인의 급성중독 등 직업성 질병자 **1년 이내 3명 이상**
- 상시근로자 **5명 미만** 개인사업주·사업장은 적용 제외(세부는 법령 확인).

### 일반 산업재해 보고(산안법 제57조, 시행규칙 제73조)
- 사망 또는 **3일 이상 휴업**이 필요한 부상·질병 발생 시 → 발생일로부터 **1개월 이내**
  **산업재해조사표**를 관할 지방고용노동관서에 제출.

### 추락 방지(안전보건규칙)
- 높이 **2m 이상** 작업발판 끝·개구부 등에서 추락 위험 시 안전난간·덮개·안전방망
  또는 안전대 부착설비 설치.
- **안전난간**: 상부 난간대 바닥면으로부터 **90cm~120cm**, 중간 난간대, **발끝막이판
  (10cm 이상)**, 난간기둥.

### 보호구(안전보건규칙 제32조 등)
- 작업조건에 맞는 안전모·안전화·안전대·보안경·방진마스크·귀마개 등 지급·착용.

## 원칙

- **추측 금지**: 사업장명·조문 번호·수치가 불확실하면 추정하지 말고 "확인 필요"로 표기.
- **국내 용어 사용**: incident→산업재해/사고, PPE→보호구, TBM→작업 전 안전점검회의 등.
- **최신 법령 우선**: 조문·기준은 항상 최신 법령정보로 검증한다.
