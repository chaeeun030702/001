# 한글 맞춤법·띄어쓰기 교정 지침

보고서 본문·표 텍스트를 작성한 뒤 이 지침으로 교열한다. 자동 검사기
(`scripts/spell_check.py`)는 아래 목록 중 **오탐이 적은 고빈도 오류만**
확정적으로 잡는다. 문맥이 필요한 항목은 검사기가 놓치므로, 생성 주체(Claude)가
아래 규칙에 따라 직접 한 번 더 훑어 교정한다.

## 2. 검사기가 놓치는 항목 — 문맥 보고 직접 교정

### 되 / 돼
- **돼 = 되어**. 자리에 '되어'를 넣어 말이 되면 '돼', 아니면 '되'.
  - 검토가 완료돼(← 완료되어) 배포 / 담당자가 되고자(← 되어고자 X) → '되고'
- 명사형·연결형은 대개 '되' : 추진되며, 구축되어, 운영된다

### 안 / 않
- **안 = 부사(아니)**, **않 = 어미(아니하-)**. '~지 않다' 자리에만 '않'.
  - 반영되지 않아 / 자료가 안 맞아(← 않 맞아 X)

### 로서 / 로써
- **로서 = 자격·지위**, **로써 = 수단·도구**.
  - 주관기관으로서 / 데이터 분석으로써(← 수단)

### 든지 / 던지
- **든지 = 선택**, **던지 = 과거 회상**.
  - 어느 방식이든지 / 얼마나 붐볐던지

### 부사 '-이' / '-히'
- 소리가 '이'로만 나면 '-이', '이/히' 섞이면 '-히'.
  - 틈틈이, 일일이, 번번이 / 꼼꼼히, 각별히, 충분히

### 개조식 종결과의 관계
- 맞춤법 교정 후에도 문체는 「본문 문체 규칙」의 명사형 종결(`~ 구축`,
  `~ 확대` 등)을 유지한다. 맞춤법을 고치다 `~합니다`류 종결로 되돌리지 않는다.

## 3. 표기 통일(보고서 관례)
- 날짜: 표의 일자 열은 `‘YY.MM.DD` 형식으로 통일(본문은 `’YY. M. D.`).
- 숫자·단위: 아라비아 숫자 + 단위 붙여 씀(3천만 원, 10%, 5개소).
- 나열 접속: '및', '등'은 앞뒤 띄어 쓰되 남용하지 않는다.

## 4. 교정 절차
1. 본문·표 텍스트 작성 완료
2. `python3 scripts/spell_check.py output/report.hwpx` 실행 → 확정 오류 교정
3. 위 2절 항목을 문맥 기준으로 직접 훑어 교정
4. `python3 scripts/style_check.py output/report.hwpx`로 문체 재점검
5. 교정 반영분으로 다시 빌드
